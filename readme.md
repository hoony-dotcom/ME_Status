# 🏥 병원 의료장비 현황 대시보드 (Medical Equipment Dashboard)

인하대병원 의용공학팀에서 원내 의료장비의 효율적인 관리, 통계 분석 및 모니터링을 위해 개발한 **Streamlit 기반 인터랙티브 대시보드 웹 애플리케이션**입니다. 

자동으로 최신 엑셀 데이터를 탐색하여 병원 내 의료장비의 자산 상태, 사용 기간, 위험도 및 부서별 보유 현황을 시각적으로 제공합니다.

---

## 🚀 주요 기능 (Features)

1. **최신 데이터 자동 탐색 및 기준일 추출**
   - 폴더 내에서 `의료기기 현황조회*.xlsx` 패턴의 파일을 자동 감지하여 가장 최근 수정된 파일을 불러옵니다.
   - 파일명(언더바 뒤 8자리)을 파싱하여 대시보드 상단에 기준일을 자동으로 표시합니다.

2. **스마트 필터링 시스템**
   - **매각완료 장비(부서코드 88)** 및 **노후불용 처리중 장비(부서코드 77)**의 포함 여부를 사이드바에서 간편하게 토글할 수 있습니다.
   - 취득일자가 없어 '납품대기'로 분류된 장비의 포함 여부를 선택할 수 있습니다.

3. **핵심 지표 (KPI) 요약 카드**
   - 전체 조회 장비 대수, 총 취득가액, 고위험 장비(3/4등급) 수, 노후/불용 검토(D등급) 장비 수를 직관적인 카드로 제공합니다.

4. **다양한 통계 및 시각화 그래프**
   - **자산 상태별 현황**: A, B, C, D 등급별 비중 및 상세 기준 안내 (도넛 차트)
   - **사용기간 기준 상태등급 현황**: 납품대기 및 3년 단위 구간별 장비 분포 (막대 차트)
   - **위험 등급별 현황**: 의료장비 위험도 등급(1~4등급) 분포 현황
   - **부서별 장비 보유 TOP 10**: 대수 및 금액 기준 상위 부서 분석
   - **의용공학팀 팀원별 관리 대수 현황**: 담당자별 장비 관리 현황 파악

5. **장비 상세 데이터 검색 및 조회**
   - 키워드(장비명, 모델명, 부서명 등) 실시간 검색 기능을 제공하여 특정 장비의 세부 정보를 빠르게 조회할 수 있습니다.

6. **사이드바 바로가기 링크**
   - 의용공학팀에서 개발한 관련 연계 앱(투자집행 계획 실적, 장비 현황 바로가기, 심평원 신고 장비 상세현황 등)으로 즉시 이동할 수 있는 링크를 제공합니다.

---

## 🛠️ 기술 스택 (Tech Stack)

* **Language**: Python 3.8+
* **Framework**: Streamlit
* **Data Processing**: Pandas, NumPy
* **Visualization**: Matplotlib, Seaborn
* **Environment**: 다크모드 최적화 UI (`#1E1E1E` 배경 및 한글 폰트 자동 설정)
