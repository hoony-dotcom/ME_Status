# 🏥 병원 의료장비 현황 대시보드 (Medical Equipment Status Dashboard)

인하대병원 의용공학팀에서 제작한 병원 의료장비 통합 관리 및 모니터링 대시보드입니다. Streamlit과 Python을 기반으로 구축되었으며, 병원 내 의료장비의 자산 상태, 사용 기간, 위험도, 부서별 보유 현황 및 취득가·보험가입가 통계를 직관적으로 시각화합니다.

---

## 🚀 주요 기능 (Key Features)

1. **최신 데이터 자동 로드**
   * 폴더 내 `의료기기 현황조회*.xlsx` 패턴의 엑셀 파일을 자동 탐색하여 가장 최신 파일을 불러옵니다.
   * 파일명에 포함된 날짜 정보를 추출하여 기준일로 자동 표시합니다.

2. **맞춤형 사이드바 필터**
   * **매각완료 장비(부서코드 88)** 포함 여부 선택
   * **노후불용 처리중 장비(부서코드 77)** 포함 여부 선택
   * **납품대기(발주 계약되었으나 검수가 완료되지 않은 장비)** 포함 여부 선택

3. **상단 KPI 요약 카드**
   * 조회된 전체 장비 대수, 총 취득가액, 총 보험가입가액, 고위험 장비(3/4등급) 대수, 노후/불용 검토(D등급) 대수를 한눈에 파악할 수 있습니다.

4. **다양한 시각화 및 분석 그래프**
   * **자산 상태별 현황**: A, B, C, D 등급별 비율 및 상세 기준 안내 (파이차트)
   * **사용기간 기준 상태등급 현황**: 납품대기 및 3년 단위 사용 연한별 분포 (바차트)
   * **위험 등급별 현황**: 1~4등급 의료장비 위험도 분포
   * **부서별 장비 보유 TOP 10**: 대수 기준 상위 부서 현황
   * **부서별 취득가 합계 TOP 10**: 장부상 취득가 기준 금액 상위 부서 현황
   * **부서별 보험가입가 합계 TOP 10**: (부외, 임차, 기증 등) 장부외 자산 환산 금액 기준 상위 부서 현황
   * **의용공학팀 담당자별 관리 현황**: 팀원별 담당 장비 대수 및 보험가입가 합계 현황

5. **장비 상세 데이터 검색 및 조회**
   * 키워드(장비명, 모델명, 부서명 등) 실시간 검색 기능 제공
   * 대용량 데이터 목록 확인 및 테이블 툴바 숨김 처리를 통한 깔끔한 UI

## 🛠️ 기술 스택 (Tech Stack)

* **Language**: Python 3.8+
* **Framework**: Streamlit
* **Data Processing**: Pandas, NumPy
* **Visualization**: Matplotlib, Seaborn
